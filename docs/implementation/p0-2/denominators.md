# P0-2a 分母定义

依据开发指南 v1.0 §5.2 P0-2 卡片及 §3.4 R02 卡片。下列章节号均指大方案 v1.2。实验内的评价单位、证据门的提交数、系统评测的预分配题数分别按各自口径统计。

| 规则 | 分母或处理要求 | 出处 |
| --- | --- | --- |
| 实验评价单位先声明 | 协议和设计先固定评价单位、范围与实际数据。附录 C 采用 `unique_item`，每个 Arm 的分母为声明的四个固定题目，每题一次。结果只描述该有限集合。 | §5.1、§5.5、§8.4、C.1–C.3 |
| 重复行不增加样本量 | 附录 C 中复制同一题的行后，`unique_item` 不变。按 C.5 去重或拒绝伪样本量，不把额外行计入分母。 | §8.4、C.5 |
| 固定集合缺失样本 | 附录 C 的 `missing_policy` 为 `incomplete_if_any_item_missing`。缺少任一必需题，科学运行资格为 `incomplete`。不得缩小分母后继续支持原主张。 | §5.3、C.2、C.5 |
| 重试保留尝试历史 | 同一 `run_id` 的基础设施重试保留全部尝试。默认取第一个满足有效性条件的完整尝试。多个完整尝试意外产生时按预注册处理，不能挑最好结果或把尝试当作独立样本。 | §5.2–5.3、C.5 |
| 确定性运行与种子 | 确定性四题集合的随机性推广目标为 `not_applicable`，不得把确定性输出复制成多个种子充当独立样本。同代码同数据重跑属于可重复性。真正多种子任务须按声明的随机性目标、独立单位、配对及簇结构估计。 | §5.1、§8.4、C.2–C.3、C.5 |
| 证据门分母 | 误放行率分母为全部不可支持的原始固定提交。误拒率分母为全部可支持的原始固定提交，截止时未接受计入未接受，按原因分别报告。缺陷检出率分母为指定缺陷的可评价包。多论断包预先拆分论断并按包聚类。 | §10.3 |
| 系统评测主分母 | FPR 分母为全部预分配假命题题数，Recall 分母为全部预分配真命题题数。超时、执行失败、证据不足和预算耗尽保留在主分母并分类。单题多次尝试按截止时最后有效锁定结论归并，保留全部尝试与成本。 | §10.5、§10.13、附录 E CHK-16 |
| 评测例外 | 评测任务未正常交付、生成器故障、参考真值错误等 evaluator 问题，才可按预注册条件在配对方案中对称作废或重跑。系统自身失败不能剔除。 | §10.5、附录 E CHK-16 |

## 待决问题

1. C.5 允许重复行去重或拒绝，尚未规定完全相同的重复行和同一评价单位下内容冲突的行如何分别处理。
2. C.2 的「缺任一题即 incomplete」绑定固定枚举协议。其他协议或采样设计的缺失判据与分母处理须由其预注册声明，当前无跨协议默认规则。

类型：text=字符串；id=不透明标识（不是自动内容 ID）；ref=待 Q-03 决定的精确版本引用；digest=完整摘要（算法/载荷按对应 Q）；decimal-string=领域精确十进制字符串；integer=严格整数（bool 不算）；object=**内部字段待补齐，不可直接实现**；list[T] 的顺序/去重规则须逐字段审定。基础解析保留精确 Decimal，不代表已实施领域字符串/JCS 规范化。

哈希分类：S=拟进入科研投影（Q-01）；X=不进入科研内容哈希，仍保存授权/审计；R=引用的科学版本投影，外部身份不混入（Q-01/02/03）；A=事实/审计/配置摘要规则未定，不假设属于科研内容对象（Q-04，涉及签名加 Q-05）；M=混合结构必须拆分，不能整体默认排除。没有任何分类获本轮 A0 批准。每行继承其对象标题的锁定规则；不确定锁定细节另归 Q-06。

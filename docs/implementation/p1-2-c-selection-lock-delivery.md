# C 组限定纯契约交付

以 A0 签收 164ed9ce41b70f06c7afe5ff5dceee2da4031763 绑定的 a837a549b61cfc177756a6560e19d9fbf9d9f98c，以及签收 4ae073622a360949d84e651b9b17d31f821f6f1b 绑定的 1c23327a2e95fd18ef308aa4958c21706fa03094 为依据。字段、写入方和保留条件见[签收字段表](p1-2-c-selection-lock-fields.md#c-s01-报告与清单版本)。

公开纯契约入口为 [SelectionReview](../../danus_ai/contracts/selection_review.py)，记录和投影见[字段实现](../../danus_ai/contracts/selection_records.py)。当前委派、租约、归属及逐引用读取许可先于受限快照和正文。端口分别提供独立版本依据与实际正文，代码按精确定位和规范字节核对。受限记录依赖由真实服务提供的事实，本包用明确的合成端口复验。

|决定|交付与复验|尚受阻|
|---|---|---|
|C-S01|六项唯一检查、现行报告与清单精确修订、逐项适用性及证据核验。blocked 优先，错误留在逐项结果。|缺试点、模板、方法、许可或任何适用性证据时，正式 ready 拒绝。|
|C-S02|独立验证 v2 签名的精确候选、报告、清单、归属及预算范围，保留 v1。合成预算依据明确为测试路径。旧批准重用于新版候选和报告时拒绝。|真实预算权威目标、budget_use 条款和正式选择签发未放行。|
|C-S03|阈值追加历史、精确上游版本和已见证据、现行旧格式阈值批准。实质变更要求新问题版本，提议无法生效。|新 ResearchQuestion 科学投影和正式启用所需独立方法与已见数据依据未齐。|
|C-S04|SelectionSet 精确引用、逐项校验、互斥子集、事件顺序，科学版本独立于历史依据。单族和集合／上游截面做精确绑定。|族签名和 protocol_use 精确组件载荷、多集合归并、跨问题和统计族仍受阻。|
|C-S05|A4 只读独立授权的摘要元数据，A7 只在受限权限下核验历史，分别返回固定白名单。|缺角色、引用或审计授权，或无对应独立摘要事实时拒绝。|
|C-S06|逐来源核对 R05、R08c 精确覆盖、截面、来源范围及事件序列。截断与缺来源阻断。|服务负责验证真实来源完整性和游标语义。|
|C-S07|同项目已定事件映射复用 R08c 实际接触校验，独立核对事件和 Dataset 版本，再计算新版历史投影。固定四题 v1 的空暴露与已批准预映像保持原样。|未知事件、用途、许可或接收方映射继续阻断。新版历史不可用于 v1 确认，旧引用无自动转换。|

固定四题只读正向路径复算已有 Prereg 预映像并核验选题及阈值的现行精确批准。完整锁定前通过仍受协议和族签名条款、校准和适用预算事实限制，真实 R06 事务锁定在服务边界。真实签发、预算执行、外发、抽样、描述型、跨 Scope 及 P1-3 不在本次交付范围。

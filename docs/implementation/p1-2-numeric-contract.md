## 交付、兼容与验证

调用方以 NumericRequest 或 FixedResultRequest 提供定位，证据和观测投影仅受信服务可解析，NumericResult 和 FixedResult 为只读输出。报价复用既有 QuoteRequest/QuoteEstimate，不强行转换原币或单位。批准阈值复用精确审批及歧义阻断。其他决定、原文、分析和推导使用独立权威投影核对命名来源、作者、完整值和单位；没有相应独立适配器或事实时拒绝。测量来源要求 R11 权威记录，普通调用方不能自报 measured。来源真实性由独立权威端口提供，正文自身及来源引用的存在不足以证明真实性。该包不验证未经批准的通用目标、推导算法或单位转换。

固定四题按既定 ratio 单位核对阈值，独立 R06 锁定事实绑定策略和两臂，R08 观测有独立摘要。calculate_fixed_result 复算，require_fixed_result 由接收方重新计算和精确比较。状态 valid 表示可计算的完整四题结果，科研接受仍经既有 G0/G1/G2。证据验证与分数计算无写入副作用。

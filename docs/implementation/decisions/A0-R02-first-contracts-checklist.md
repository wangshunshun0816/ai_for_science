## 1. 已按设计落实，无需重复批准

- 草稿不接受有效身份、批准、实际摘要/测量字段；RunRequest 无 status，执行态在 Attempt，科学有效性另存。依据 A §5.1–5.3、R §3.5。
- 唯一 content_version；ScientificRef / HistoricalRef 与 ApprovalLocator / RecordLocator 分型；字段别名只显式迁移。属于工程组织，不改变精确版本/归属原则。
- BindingSpec 改为独立 ExecutionBinding，不指向 RunRequest/报告；MethodConfig 不含父对象，消除结构循环。A §6.16。
- 科学方法限额只存在 MethodConfig.science_limits；试验停止规则由锁定 Prereg/复现计划负责，重复值/冲突直接拒绝，不逐层覆盖。
- A0 作设计规定的科研/预算/数据等批准；R06 lock、R09/R08 run_authorize 是服务操作，**不新增逐run人工签字**。A §3.9/4.1/4.2/6.9、R §4.4。科研变更须新版本/适用批准也不是重新开放的选项。

设计链接与章节索引见提案开头，下面的 A/G/R 与该文一致。结构已修订不代表代码已实现、科研投影已批准或人工验收完成。

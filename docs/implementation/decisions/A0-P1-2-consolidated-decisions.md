状态为 A0 已于 2026.11.15 有条件签收，文件系统、UID、权限和空间现场核验全部通过后生效。签收范围仅限本专节第 1 节「材料、写入与精确版本」、第 2 节「受控测试身份及查询返回」和第 3 节「隔离测试库与验收门槛」。预算、数据外发及运行库均不在本组批准范围，继续未批准。D-02 的本地 SQLite/WAL 与 WSL/ext4 沿用。

### 1\. 材料、写入与精确版本

推荐仅保存私有、单项目的 CandidateHypothesis 草稿，由受控测试服务接收 CandidateDraft 并组装 CandidateRecord。以下清单取自 [CandidateFields、RecordMetadata 和 CandidateRecord](../../../danus_ai/contracts/first_objects.py#L35)及[引用定义](../../../danus_ai/contracts/references.py)。保留现有必填、可空、字面量、列表和来源分支规则。

|写入字段|填写方与约束|
|-|-|
|background、new\_inference、prediction|调用方填写候选内容。|
|draft.format、draft.body|调用方填写。format 固定为 plain\_text。|
|sources\[]|调用方逐项填写 snapshot\_ref 和 location。snapshot\_ref 含 object\_type、object\_id、content\_version；location 含 kind、locator。|
|original\_source|调用方填写，按现有分支要求为同形 SourceRef 或 null。|
|source\_kind、synthetic\_origin|调用方填写，沿用原枚举、可空性及分支校验。|
|scope\_ref|调用方填写 object\_type、object\_id、content\_version，类型必须为 Scope。|
|object\_id|受控服务分配或从该项目已存在的材料身份确定。普通草稿不填写。|
|content\_version|受控服务按现有 candidate:v1 科学投影计算，保存后从记录重算核验。|
|tenant\_id、project\_id、ownership\_scope|受控服务根据受信上下文与已核验归属填写，project\_id 非空，ownership\_scope 固定 project。|
|created\_at、created\_by|受控服务写入服务时点及受信测试主体。|
|status、approval\_bindings|受控服务组装本切片初始草稿，status 为 draft，approval\_bindings 为空列表。切片没有批准写入入口。|
|comment、display\_name、cache\_location|沿用现有可选元数据定义；本切片省略，按原合同保留缺省，不接受调用方写入。|

在计算版本前，逐条核验 scope\_ref、所有 sources\[].snapshot\_ref 和存在时的 original\_source.snapshot\_ref，包括精确引用版本、当前可读与归属。夹具必须提供这些依赖，且核验先于投影去重。使用已有来源准入规则，不新增跨项目或公共可见性。CAS 摘要只校验保存字节。[版本守卫](../../../danus_ai/contracts/projections.py#L58)

### 2\. 受控测试身份及查询返回

推荐以受控夹具装配两个租户，其中一个租户下两个项目。服务端装配测试账号、主体、委派、用途、租约和签发时的归属修订；测试身份仅用于验证守卫，真实认证另行验收。现有 references.resolve 仍按原合同返回精确定位。测试切片的本地授权查询按指定候选 ID 和 content\_version 读取，在打开正文前复验当前归属、委派、租约、用途与目标，并核对记录和制品完整性。查询限定单项目指定版本。

|成功查询返回|精确字段|
|-|-|
|候选定位|object\_id、content\_version|
|候选正文|background、sources、new\_inference、prediction、draft、original\_source、source\_kind、scope\_ref、synthetic\_origin；嵌套字段沿用上表|
|不返回的 CandidateRecord 字段|tenant\_id、project\_id、ownership\_scope、created\_at、created\_by、status、approval\_bindings、comment、display\_name、cache\_location|

成功返回只投影上述已有字段。引用仅返回定位，不附所引用材料正文、委派内部事实、CAS 摘要或磁盘路径。拒绝路径沿用现有错误边界，不暴露其他归属下同 ID 或同摘要材料是否存在。无跨项目搜索、未认领读取或最新版本回退。[委派查询守卫](../../../danus_ai/contracts/messages.py#L178)

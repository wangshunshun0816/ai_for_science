## 科学版本、批准和锁定顺序

1. **先算上游候选与问题材料版本。** 对已定投影使用现行规范字节与内容 ID。R17 对该候选精确版本给出独立报告。历史对象的稳定实体与修订同内容身份分开，待定投影不得生成正式科学 ID。
2. **再核验上游批准。** R09 以已有选题／阈值用途及精确候选／问题和科学条款签发或验证。按审定方案核验报告、预算范围、签署人、当前性及撤销／冲突。报告先于批准；报告和上游批准均无需最终 Prereg ID。族批准指向拟锁定的族版本及所依赖历史；其签名条款齐备前继续阻断完整路径。
3. **计算拟锁定 Prereg 科学版本。** 输入是草稿、精确候选／协议／问题／族／历史引用、SelectionTerms、ThresholdTerms 和其他已有依据的科学输入。锁定依赖中的声明版本、阈值历史、随机性与适用区分性设计按设计进入投影。批准定位、签署身份、时刻和纯预算留在授权／审计记录。对既定固定四题投影做原样回归；通用投影须待目标规范与字段表齐备，避免用空字段改变既有科学版本。
4. **锁定前对照精确版本核验。** 校验归属、版本、报告和批准的精确对应、协议／族签名条款、校准、预算可行性、历史完整性和读取权限。任何更替、冲突或缺依据产生阻断。同一项目的科学版本计算与锁定前检查分别有结果。现有固定四题 check_lock 明确阻断 protocol_use 和 family_confirmation 的签名条款缺项；保留该阻断，不以合成成功回执冒充完整锁定前校验。
5. **真实锁定由 R06 执行。** 服务按精确修订重验并以事务持久化锁定时刻、版本及审计记录。复核纯契约过程不存在以锁定记录反证前置有效性的循环，也不要求为同一预注册另设人工签字用途。

## 本轮补充核对：首包边界与可审阅的决定粒度

本节为 2026-11-16 文档核对结果，不是新增批准。依据大方案 §6.26、§8.3 和附录 C.2，以及首组 P2/P4 的固定枚举批准范围。

### 固定四题与通用统计族分开

固定四题采用 finite_population_enumeration，不走抽样 p 值检验；沿用已批准的 `test=null`、`family_alpha=null` 及不适用理由。族身份、历史和防止改名重置的校验仍适用，但不得将 §8.3 的通用 α=0.05、K=3 或 Holm 默认注入此分支。通用抽样分支的默认规则是既有设计，不代表本包获得启用许可。选择 C-04 的任一方案均不改变这一边界。

### C-01 A 建议，待 A0 签收

A 提议采用下列六项检查矩阵和下文的 blocked 优先规则。B 仅保留现行证据已经覆盖的固定四题轮廓，对未决条件统一阻断。检查键命名、类型组织及错误码由工程映射，各检查面仍需独立留证。

| 检查面 | 推荐必需证据与 ready 条件 | 缺项处理 |
| --- | --- | --- |
| 来源与相关工作差异 | 可读的精确来源及位置、相关工作／冲突与候选差异的审核依据 | 缺来源或差异证据不 ready；不宣称全球首创 |
| 可检验预测与关键对照 | 同一候选版本的预测、测量对象、对照及最小验证材料；机制问题另核独立区分依据 | 不可测、缺关键对照或方法依据未就绪不 ready |
| 数据与许可路径 | 精确数据版本、可得性及适用许可证据；数据政策和许可分别核验 | 无数据、伦理或许可依据未定时不 ready，不以只读约束通过代替授权 |
| 算力与预算可行性 | 所需资源依据、R07 估价及其适用版本、可核验的预算路径 | 缺报价／预算路径或额度不足不 ready；估价不授予预占或扣款 |
| 试点／模板 | 按适用依据要求的试点结果和模板精确引用；确实不适用时给出目标与依据 | 未知适用性不按“不适用”放行 |
| A7 candidate_review | 对当前候选及验证草案的精确审核结果与未解决阻断项 | 缺审核、服务错误或仍有阻断项不 ready |

推荐的状态区分：能够指向 A2/A4 的具体材料修订、且不缺外部批准或方法规则时为 needs_revision；缺权威依据、方法适用规则、权限、可行资源，或存在未解决冲突时为 blocked。二者同时存在取 blocked 并保留全部原因。执行错误单独保留错误事实，不能伪装科学否定或 ready。此优先级属于 C-01 待审规则。ready 仅表示具备交给 A0 选题的材料与可行路径，不表示候选已获选、科学主张成立或已允许运行。

### 版本图与复核要求

候选精确版本 → R17 报告与检查清单 → R09 选题决定；问题与阈值历史、族及选择历史分别提供精确上游版本 → 拟锁定 Prereg 科学版本 → 当前授权与锁定前校验 → R06 真实锁定。任何上游对象不得要求引用下游锁定回执来证明自身有效。族确认签名针对拟锁定版本，不以最终锁定状态作为签名前置。

同修订正文须对独立权威版本依据核验，当前撤销／有效性与版本不可变依据分开；权限先于受限快照和正文读取。验收增加同修订成对替换报告与决定、替换阈值历史、伪造集合完整性三类反例。不能因为引用可解析便认定历史全集完整；需要权威范围与完整性依据，缺失时拒绝适用锁定路径。
